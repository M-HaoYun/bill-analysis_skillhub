# 家庭财务规划方法论（资产配比 + 还贷策略）

> 用途：在完成月度收支分析后，若用户进一步问「钱该怎么配」「房贷要不要提前还/怎么还」，按本文方法论测算并输出建议。
> 通用原则：本文只含方法论与公式，**不含任何个人数据**；所有测算用 `scripts/planning_calculator.py`，输入参数由用户实际情况提供（或从工作区账户总览/收支数据中提取）。

## 何时触发

| 用户问题 | 处理路径 |
|---|---|
| 存款/股票/公积金怎么分配？ | 走「四笔钱」资产配比 → `allocate` |
| 房贷要不要提前还？还多少？ | 现金流承受力判断 → `prepay` |
| 提前还本后选「减月供」还是「缩年限」？ | 直接两方式对比 → `prepay` |
| 降薪/失业/绩效停发后扛不扛得住？ | 情景现金流 → `cashflow` |
| 用配偶公积金还贷可行吗？ | 查当地政策（本文件第 4 节通用要点） |

## 1. 四笔钱框架（资产配比基准）

不按"产品"分钱，按**用途与时间**分四笔，优先级不可颠倒：

| 笔 | 金额基准 | 工具 | 铁律 |
|---|---|---|---|
| ① 应急金 | 月现金支出 × N 个月 | 货币基金/活期 | **绝对不动**；N 的校准：收入稳定家庭 3-6 个月；有降薪/失业风险按最坏情景 10-12 个月 |
| ② 生育/大额计划金 | 未来 1-3 年确定要花的钱 | 定存/储蓄国债 | 到期时间对齐用钱时点；这笔钱就该"低收益高确定" |
| ③ 还贷池/稳健仓 | 超额现金（见下） | 提前还贷 = 锁定贷款利率 | 贷款利率 > 存款利率时，还贷优于存银行 |
| ④ 权益仓（股票/基金） | 长期不动的闲钱 | 指数基金等 | 设总仓位上限，只放"亏了不心疼"的钱 |

**超额现金判定**：`可动现金 − 应急金 − 生育金 = 超额`。超额为正且无近期大额计划 → 优先还贷（锁利差）；超额为负 → 先保流动性，不谈还贷/投资。

**股票仓位参考**（生命周期法则"100 − 年龄"，但必须打折）：
- 打折条件（任一不满足则不能按法则执行）：收入稳定、无 1-3 年大额刚性支出、闲钱充足
- 现金流脆弱期（降薪风险 + 结婚生娃）：0-10% 合理，不加仓就是纪律
- 现金流稳定后：用**月度定投**缓慢爬坡（如 500-1000/月），目标 10-15%，禁止一次性梭哈

**再平衡纪律**：每年检查一次比例；任一类偏离目标 5 个百分点以上才动手；再平衡工具 = 新收入的定向投入，不是割肉搬家。

## 2. 等额本金还贷公式（脚本已内置）

- 贷款 P、期数 N、月利率 r（= 年利率/12）
- 月还本 m = P / N
- 第 k 期利息 = (P − m·(k−1)) · r；第 k 期月供 = m + 该期利息
- 总利息 = r · (N·P − m·N·(N−1)/2)
- 已还 q 期后剩余本金 = P − m·q

**判断口诀**：等额本金下本金还得越快、停息越快 → **缩短年限在省息上永远优于减月供**，唯一代价是月供更高。选哪种取决于：月供（或公积金覆盖后自付）是否扛得住。扛得住 → 缩期；扛不住 → 减月供。

## 3. 提前还本两方式对比

以「剩余本金 P′、月还本 m」为基准，提前还 A：

| | 方式一：年限不变（减月供） | 方式二：月还本不变（缩年限） |
|---|---|---|
| 剩余本金 | P′ − A | P′ − A |
| 剩余期数 | 原剩余期数不变 | ⌈(P′ − A) / m⌉（明显变短） |
| 月供 | 降低 | 基本持平（略降） |
| 省息 | 少 | **多**（提前 N 年停息） |
| 适用 | 现金流紧、需要降月供 | 现金流 OK、想最大化省息 |

**组合拳经验**（可复用的决策顺序）：
1. 小额定金、近期可能还要用钱 → 还本选「减少月供」（不动期限、保流动性）
2. 大额现金、确定短期不用 → 还本选「缩短年限」（把唯一一次期限变更机会留给最大的那笔）
3. 全部还本动作做完 → 再办「按月冲还贷」（见下，部分城市冲还贷期间不能提前还本，顺序不能反）

## 4. 公积金政策通用要点（各地细节须现场核实）

- **提前还本最早时点**：通常需正常还款满 1 年
- **期限变更**：很多城市一生仅限一次 → 用在哪笔、哪个时点要想清楚（缩期省息随剩余本金减少而贬值，越早用越值钱）
- **按月冲还贷**：签约期间部分地区**不能办理提前还本/结清** → 操作顺序：先还本、后签约
- **配偶公积金**：多数城市配偶（结婚登记后）可办理冲还贷/还贷提取/还本，**通常不要求配偶是产权人或共同借款人**，只要求夫妻关系 → 婚前购房婚后配偶公积金大多可用，前提是**已领证**
- **缴存基数**：通常每年 7 月按上年度月均工资重算（含绩效奖金）→ 降薪的次年 7 月起缴存才会下降，当年内不变
- **贷款代际判断**：公积金利率 > 存款利率 → 有余钱适度还贷是理性（等于买无风险收益）；利率整体下行期则"还贷不急、应急金优先"

## 5. 现金流情景模拟（降薪/失业压测）

对"收入结构里某块消失"做敏感性测试，参数化四档（可自行扩展）：
1. 现状（各项收入全在）
2. 绩效/奖金停发（最脆弱的一块先砍）
3. 停发 + 降薪 10-15%
4. 全面恶化（叠加公积金缴存基数下调 → 房贷自付上升）

每档输出：月收入 / 月支出 / 月净现金流。**月净转负 = 现金储备在燃烧**，用「现金储备 ÷ 月亏损额」算出还能撑几个月，再决定防御动作（砍支出 > 停大额动作 > 最后才动应急金）。

## 6. 输出建议（HTML 报告）

测算完成后建议生成单文件 HTML 报告（浅色金融仪表盘风格，与收支分析工作台观感一致）：
- 顶部结论区：Hero 卡（深色渐变底、金色高亮核心结论）
- 数据表：方案对比（th 深底白字、斑马纹）
- 关键结论用 `.insight`（米黄底金边）高亮；风险用 `.warnbox`/`.dangerbox`
- 行动清单按时间分阶段（现在/婚后/未来）标注
- 测算数字与结论必须在同页可见，用户可自查
